# Radeon Cloud Connector Release Hardening Implementation Plan

**Goal:** Bring the completed Radeon Cloud Connector to a reproducible, reviewable release state with synchronized artifacts, regression coverage, publication metadata, and explicit submission blockers.

**Architecture:** Keep the connector as a WorkBuddy Skill wrapping the existing `scripts/rc.py` CLI. Add only release-level repository files and targeted regression tests; do not convert it into an MCP Connector without an official protocol contract. Treat source files as the single source of truth, then regenerate the installed copy and ZIP.

**Tech Stack:** Python 3.10+ CLI (PEP 604 union syntax), unittest, tarfile, SSH/OpenSSH, GitHub Actions, Markdown, ZIP distribution.

**Files:**
- Modify: `scripts/rc.py`
- Test: `tests/test_rc_regressions.py`

**Steps:**
1. Add failing tests for status probe failures, job metadata write failures, and unsafe archive members.

5. Have an independent subagent verify the behavior and test strength before proceeding.
